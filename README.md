# GreenBasket Supermarket — Complete XAMPP Website

## Installation
1. Install XAMPP and start Apache + MySQL.
2. Copy this folder to `C:\xampp\htdocs\greenbasket_supermarket`.
3. Open `http://localhost/phpmyadmin`.
4. Import `database.sql`.
5. Open `http://localhost/greenbasket_supermarket/`.

## Admin
Email: `admin@greenbasket.co.tz`
Password: `password`

## Notes
- The frontend is Swahili and follows the supplied GreenBasket reference: dark green/lime palette, hero, categories, offers, product cards, newsletter and footer.
- Product photos are local crops from the supplied GreenBasket real-produce artwork, so the site works without external image URLs.
- Product catalogue includes fresh produce, dairy/eggs, pantry staples, meat/fish, drinks, household, personal care and snacks.
- Prices are representative Tanzanian-market prices and should be updated by the supermarket admin as supplier prices change.
